# المكتبة الإسلامية

صفحة ويب مستقلة (لا تحتاج خادماً ولا تثبيت) تضم:

- **القرآن الكريم**: فهرس السور الـ114، قراءة بالرسم العثماني، ستة تفاسير (الميسر، الجلالين، البغوي، القرطبي، الوسيط، تنوير المقباس)، تلاوة الشيخ مشاري العفاسي آيةً آية أو للسورة كاملة، بحث في الآيات، وحفظ موضع آخر قراءة.
- **قصص الأنبياء**: الأنبياء الخمسة والعشرون مرتبين زمنياً مع القصة والعبرة وأبرز السور.
- **الصحابة** و**الصحابيات**: سير مختصرة مع تصنيفات (العشرة المبشرون، الخلفاء، أمهات المؤمنين…).
- **الغزوات**: أبرز الغزوات والسرايا مرتبة زمنياً بالتاريخ والقوات والنتيجة.

## التشغيل
افتح `index.html` في المتصفح. قسم القرآن يحتاج اتصالاً بالإنترنت لأن النص والتفسير والتلاوة تُجلب من
[api.alquran.cloud](https://alquran.cloud/api) حرصاً على مطابقة المصحف، أما بقية الأقسام فتعمل دون اتصال.

## إضافة محتوى
كل المحتوى التعريفي في `data.js` (المصفوفات `PROPHETS`, `SAHABA`, `SAHABIYAT`, `GHAZAWAT`)؛ أضف عنصراً جديداً بالشكل نفسه وسيظهر تلقائياً.
